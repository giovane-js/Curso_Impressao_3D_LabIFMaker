# Perfis Oficiais do UltiMaker Cura (`.curaprofile`)

Esta pasta destina-se ao armazenamento dos perfis de fatiamento validados na bancada do **LabIFMaker (IFSP Campus Salto)** após a execução das torres de calibração para **PLA**, **PETG** e **ABS**.

## Como importar um perfil no UltiMaker Cura
1. Baixe o arquivo `.curaprofile` desejado desta pasta.
2. No UltiMaker Cura, acesse **Preferences > Configure Cura > Profiles**.
3. Clique em **Import** e selecione o arquivo baixado.
4. Ative o perfil correspondente à impressora e ao filamento que você utilizará no laboratório.
